# Alen Johnson — Portfolio

A cinematic, scroll-driven portfolio for Alen Johnson, a full-stack MERN developer.

- Full-bleed hero photo with "ALEN JOHNSON" layered behind the head
- Scroll-scrubbed 3D cube, a draggable MERN cube, pixel-reveal images, parallax layers
- Projects, experience, skills, education and contact, all built from the resume and LinkedIn profile

## Running it

This is a single static page — no build step, no dependencies.

Open `index.html` directly in a browser, or serve the folder locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Hosting on GitHub Pages

In this repo's **Settings → Pages**, under "Build and deployment", set **Source** to `Deploy from a branch`, branch `main`, folder `/ (root)`, then save. The site will be live at:

`https://darkzzz005.github.io/alen-johnson-portfolio/`

## Editing content

Everything — text, links, project details — is in `index.html`. The photos are in `photos/`.
